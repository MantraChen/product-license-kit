# 后续演进

## 0.1 已提供

通用目录、身份接口、KOOK token 验证、邀请码、用户会话、永久版本权益、固定价升级、人工付款确认、设备挑战、自然月换绑、额外次数、短期签名许可证、分发追溯清单、事务通知、管理 API、Node SDK、端到端本地示例和 CI。

## 0.1.1 与 0.2 已提供

账号启停及宿主策略、嵌套事务、私有目录保护、单进程锁、限并发密码散列、浏览器 CSRF 边界、加密备份恢复、手动密钥轮换已有实现。0.2 增加可信历史授权认领、同版 Beta、最低固定升级价和迁移 3。当前完整能力见 [系统手册](SYSTEM-GUIDE.md)。

## 0.3 与 0.4 已提供

设备自助重置及迁移 4；订单有效期、过期付款显式人工复核及迁移 5；256 MiB 原始内容备份上限与旧格式兼容。账号找回、网页 MFA 和 KOOK 工单属于宿主产品能力，不能把 V6 已有功能误记为框架内置功能。

## 下一阶段候选

1. 用户中心与独立管理端：真实 OAuth 跳转、MFA、操作员权限、明确换绑确认。
2. Bot 交互适配器：购买入口、按钮事件验证、一次性注册交接、通知调度。
3. 正式支付适配器：已验证的商户回调、主动查单、退款和对账。
4. 文件 worker：受控发布基线、产品格式个性化、平台签名、私有制品与短时下载。
5. 平台 SDK：Windows 安全存储、HWID 信号、C#/Rust 客户端接入测试。
6. 运维扩展：异步仓储/PostgreSQL、分页、后续兼容迁移、多节点限流与任务租约、自动轮换调度。

扩展前先确定接口与失败语义。收费版本、设备组和外部平台的产品规则留在配置及适配层，避免把某个具体产品写进核心。
