## 下一阶段候选

2026-11-18 已在工作区增加订单、已完成分发和管理员审计的游标分页，通过库方法及原 HTTP 入口使用。游标按创建时间与 ID 倒序，绑定账号和列表类型，每页最多 100 条；无查询参数的原入口继续返回数组。分发按当前权益筛选后再分页。异步业务入口另见下方 PostgreSQL 记录；多节点调度继续列入后续工作。

工作区另提供 KookOAuthClient，宿主验证浏览器 state 后可交换 KOOK 授权码，并通过现有 IdentityProvider 和框架注册／登录入口核实平台 token。Cookie、MFA 及操作员权限由宿主衔接，EXAMBIA 工作区已接入相应流程并执行本地隔离验证。平台真实授权验收需开通应用的 OAuth 资格。

2026-11-18 工作区迁移 7 为事务事件增加精确资源引用，通知适配器收到可选 `resource`；订单和分发不再仅能按账号识别。旧事件保持未关联，不猜测历史关系。该事件资源接入阶段的框架 82 项测试通过，包含并行时点的多订单区分、失败重试保持同一事件、资源写入失败与付款一起回滚，以及旧库重复迁移。产品通知消费、渠道策略、退避、过期和结果不明核销由宿主实现；EXAMBIA 工作区已接入付款通知账本及管理页面并完成模拟平台验证，默认关闭，真实 KOOK 发送仍待验收。框架通用 dispatchNotifications 不因此获得宿主的任务租约或投递核销能力。

2026-11-18 工作区新增 [C#／Rust 原生 SDK](../clients/README.md)。两端的 Ed25519／RSA-PSS 设备证明、许可证与分发验签完成回环 HTTP 联调；Windows 软件密钥使用同一 DPAPI 格式、产品／账号范围、私密 ACL 与文件锁，双向互读及两端实际 HWID 摘要一致性通过。缺失身份默认拒绝创建，损坏密文不替换。C# 为 30 项本地检查和 76 项 HTTP 检查；Rust 为 5 项测试和 77 项 HTTP 检查，Clippy 严格检查通过。测试目标为本机 Windows x64，未验证其他系统，也未内置产品 TPM 证明或更换产品现有客户端。下面第五项的通用软件身份与跨语言接入已有此实现，其他平台及硬件适配继续按目标环境验证。

2026-11-18 异步仓储接口与 PostgreSQL 适配器已完成本机 18.7 的 19 项集成检查，包括双进程并发迁移、精确整数、事务／保存点、连接断开与截止时间、提交结果不明、TLS 主机名及最小权限验证。独立迁移 1 建立对应 SQLite v7 领域布局的 20 张表，并记录内容摘要。参见 [接口与验收](POSTGRESQL.md)。随后新增 AsyncFramework，账号／订单／权益／设备／分发等全部业务接入异步 unit，现有 HTTP 兼容同步与异步实现；SQLite 与真实 PostgreSQL 共用九组契约，并完成跨实例业务竞争和 C#／Rust 回环 HTTP 验证。现有同步 Framework 不接收 PostgresStore，使用 PostgreSQL 应显式创建 AsyncFramework。尚未切换产品数据库；后续多节点限流与通用任务租约的本地实现见下段，自动轮换仍未完成。

2026-11-18 后续实现 [PostgreSQL 多节点协调](COORDINATION.md)：共享 HMAC 限流预算、持久任务／租约／心跳／generation、退避与发送结果不明核销，AsyncFramework 的通知事务已接线。两个独立 Node 进程共享 12 次预算、20 个任务各完成一次，并向真实回环 HTTP 接收器投递十条唯一合成通知。原同步 Framework 和产品仍使用既有部署边界；生产配置、恢复验收、具体制品任务适配及自动轮换调度继续推进。

2026-11-18 EXAMBIA 产品另实现服务端授权签名的指定计划执行：预分发双公钥后取全量在用基线快照，监督进程在窗口内停 API/Bot、备份、启用准备钥、原子刷新制品标记及审计后恢复服务；恢复备份会暂停未完成计划。该宿主能力默认关闭，已做隔离真实监督进程和 HTTP 公钥交接验证；不表示通用框架内置任意部署的自动换钥，也不表示生产客户端过渡验收完成。框架手动 rotateSigningKey 保留原职责。

2026-11-18 后续通用异步框架已增加 [PostgreSQL 签名自动计划与加密恢复](POSTGRES-SIGNING.md)。共享策略在签发事务中选定当前钥，节点须用候选私钥证明就绪；计划通过有租约的控制进程和备份回执启用，失败／结果不明暂停，恢复只进入空 schema 并暂停未完成外部任务。参考 PostgreSQL 服务提供共享限流、节点心跳和受保护的管理入口，默认自动执行关闭。此实现不将产品改为 PostgreSQL，也不替代目标部署、真实客户端信任过渡或正式 EXE 签名验收。

1. 用户中心与独立管理端：真实 OAuth 跳转、MFA、操作员权限、明确换绑确认。
2. Bot 交互适配器：购买入口、按钮事件验证、一次性注册交接、通知调度。
